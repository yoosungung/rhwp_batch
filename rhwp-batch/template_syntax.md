# template_syntax.md — 양식 마커 문법 정본

> **역할**: `fill` 명령이 양식 HWP 안에서 인식하는 마커 문법과 치환 정책의 정본 문서.
> **권한 우선순위**: [ROADMAP.md](../ROADMAP.md) D3·D12·D14·D16·D17 > 본 문서 > 코드.

---

## 1. 마커 외곽

모든 마커는 이중 중괄호로 감싼다: `{{ ... }}`.

- 양식 본문에 **`{{` 리터럴은 금지** (D16, v1 escape 미지원).
- 마커 내부 표현식은 양옆 공백을 자동 제거한다.
- 줄바꿈을 포함한 마커는 동작이 정의되지 않음 — 한 문단 내에 마커가 닫혀야 한다.

---

## 2. 3종 prefix (D3)

| 형태 | 용도 | 마일스톤 |
|------|------|---------|
| `{{expr}}` | 단순 텍스트 치환 | M3 |
| `{{table:expr}}` | 표 행 동적 확장 | M4 |
| `{{image:key}}` | 이미지 삽입 (양식 내 동일 위치) | M4 (예약, v1.1) |

`expr`는 [JMESPath](https://jmespath.org/) 표준 (D12). 자체 정의 문법 금지.

---

## 3. 단순 치환 `{{expr}}`

### 예
```hwp
주문자: {{customer.name}} (전화 {{customer.phone}})
주문일: {{order.date}}
```

### 데이터
```json
{
  "customer": { "name": "홍길동", "phone": "010-1234-5678" },
  "order":    { "date": "2026-04-27" }
}
```

### 결과
```
주문자: 홍길동 (전화 010-1234-5678)
주문일: 2026-04-27
```

### CharShape 보존 규칙

치환 후 마커 앞 텍스트의 글꼴·크기·색상은 **보존**한다.
구체적으로 `char_shapes[i].start_pos`(UTF-16 기준)를 마커 길이 변화량만큼 시프트한다.
`line_segs`는 무효화하여 뷰어가 페이지네이션 시 재계산하도록 한다.

### 평가 결과 → 문자열

| JMESPath 결과 | 문자열 |
|--------------|-------|
| string | 그대로 |
| number | `Display` (정수는 `123`, 실수는 `1.5`) |
| bool | `true` / `false` |
| null | 공백 (`OnMissingKey` 정책 적용) |
| array / object | JSON 직렬화 (디버그 용도, 양식 사용 비권장) |

## 4. 표 행 확장 `{{table:expr}}` (D21)

### 양식 (1 헤더 행 + 1 템플릿 행)
| 품목 | 수량 | 단가 |
|------|------|------|
| `{{table:items[].name}}` | `{{table:items[].qty}}` | `{{table:items[].price}}` |

### 데이터
```json
{
  "items": [
    { "name": "사과", "qty": 3, "price": 1500 },
    { "name": "배",   "qty": 2, "price": 3000 }
  ]
}
```

### 결과 (헤더 + 데이터 N행)
| 품목 | 수량 | 단가 |
|------|------|------|
| 사과 | 3 | 1500 |
| 배 | 2 | 3000 |

### 규칙

1. **단일 템플릿 행만 인식**: 첫 번째 `{{table:...}}` 마커가 있는 행이 템플릿. 같은 표 안에 여러 템플릿 행이 있어도 첫 번째만 사용한다.
2. **배열 표현식 추출**: `items[].field` → 배열은 `items`. 마지막 `.field`는 행 내 셀별 키.
3. **빈 배열**: 템플릿 행을 통째로 제거.
4. **셀 분할**: 템플릿 셀의 글꼴·테두리는 복제된 모든 행에 동일하게 적용.
5. **그 외 행**: 위치는 자동 시프트 (행 인덱스 + `len(items) - 1`).

### 제약 (v1)

- 한 행 안에서 다른 배열을 섞을 수 없다 (`{{table:a[].x}}`와 `{{table:b[].y}}`를 한 행에 같이 두면 첫 마커의 배열만 사용).
- 중첩 표 안의 표 마커 — v1 미지원.
- 표 외 위치 (paragraph 내 등)에서 `{{table:...}}` 마커 — 무시 (치환되지 않음).

## 5. 이미지 마커 `{{image:key}}` (예약)

v1에서는 마커 인식만 하고 치환은 미구현 (M4 Stage 4 예약).
v1.1에서 `data.assets[key]`의 base64 또는 path를 읽어 양식 내 그림 위치를 교체한다.

## 6. 누락 키 정책 `--on-missing-key` (D14)

| 값 | 동작 | 종료 코드 | 기본값 |
|----|------|----------|:-----:|
| `error` | 마커 평가 결과가 `null`이면 즉시 실패 | 1 (single) / 4 (배치 부분 실패) | ✓ |
| `empty` | 빈 문자열로 치환 | 0 | |
| `keep` | 마커 원문 (`{{expr}}`)을 그대로 보존 | 0 | |

**`error` 기본 권장**: 양식과 데이터의 정합성을 강제하여 잘못된 출력 발생을 방지.

---

## 7. 출력 충돌 정책 `--overwrite` (D17)

| 상황 | 종료 코드 |
|------|----------|
| 출력 파일 부재 | 0 |
| 출력 파일 존재 + `--overwrite` 미지정 | 3 (`OutputExists` 에러) |
| 출력 파일 존재 + `--overwrite` 지정 | 0 (덮어쓰기) |

배치 모드에서는 항목별로 동일 정책 적용. 한 항목이 충돌하면 그 항목만 실패 (`on-error=continue` 시 다음 항목 진행).

## 8. 마커 escape 부재 (D16)

v1에서 `{{` 리터럴을 출력에 남기는 escape 문법은 **없다**. 양식 작성 시 우회:

- 회피 1: 양식에서 `{` 한 글자만 사용하고, 이중 중괄호는 데이터에서 주입 (`{{val}}` → `data.val = "{{literal}}"`).
- 회피 2: 양식의 `{{`를 다른 유사 문자(`〔〔` 등)로 교체.

v2에서 `\{{` 또는 `{{!literal}}` 형태 escape 도입 검토 (별도 결정 항목).

---

## 9. 처리 위치

마커는 다음 위치에서 모두 인식된다:

- 본문 paragraph
- 표 셀 내부 paragraph
- 머리말(Header) / 꼬리말(Footer) paragraph
- 각주(Footnote) / 미주(Endnote) paragraph

도형(Shape) 내부 텍스트, 글상자, 수식 내부는 v1 미지원.

## 10. JMESPath 빠른 참고

| 표현 | 의미 |
|------|------|
| `name` | 루트의 `name` 키 |
| `customer.phone` | 중첩 |
| `items[0].name` | 배열 인덱스 |
| `items[].name` | 배열 전체 (table: prefix 전용) |
| `items[?qty > \`5\`].name` | 필터 (table:만, v1.1) |
| `length(items)` | 함수 호출 |

전체 문법은 [jmespath.org](https://jmespath.org/) 참조.
